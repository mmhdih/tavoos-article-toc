اولین نسخه مستقل **فهرست مقاله طاووس / Tavoos Article TOC**.

برای نصب، فایل **tavoos-article-toc-1.0.0.zip** را از بخش Assets دانلود و در وردپرس بارگذاری کنید. فایل‌های Source code بسته نصب افزونه نیستند.

- ساخت فهرست خودکار از تیترهای H2 تا H6
- پشتیبانی فارسی، انگلیسی و راست‌به‌چپ
- تنظیم عنوان، نوع محتوا، حداقل تیتر، محل نمایش و حالت بازشدن
- لینک مستقیم به تیتر، پیمایش با صفحه‌کلید و رعایت تنظیم کاهش حرکت
- حفظ شناسه‌های موجود تیترها و جلوگیری از فهرست تکراری کنار کد قدیمی طاووس
- بدون API خارجی، CDN، رهگیری یا ذخیره اطلاعات بازدیدکننده
- README فارسی، آموزش تصویری، لوگو و برندبوک

**نیازمندی‌ها:** وردپرس ۶٫۲ به بالا، PHP ۷٫۴ به بالا، JavaScript فعال. اعتبارسنجی محلی روی وردپرس ۶٫۸٫۳ و PHP ۸٫۴ انجام شده؛ ۱۴ بررسی کاربردی موفق بوده و ZIP از بارگذار واقعی وردپرس نصب شده است. حداقل نسخه‌ها، آخرین وردپرس، چندسایتی و Plugin Check هنوز جداگانه بررسی نشده‌اند.
